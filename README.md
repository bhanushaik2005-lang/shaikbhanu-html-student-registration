# HTML Student Registration Form

A simple student registration form created using HTML.

## Author

**Shaik Bhanu**

## Repository Name

`shaikbhanu-html-student-registration`

## File Name

`registration.html`

## Description

This project demonstrates how to create a student registration form using HTML form elements.

## Features

* Full name input
* Email input
* Password input
* Phone number input
* Date of birth
* Gender selection
* Course selection
* Skills selection
* Address field
* Register button
* Reset button

## Requirements

* Any modern web browser such as Chrome, Firefox, or Edge

## How to Run

1. Save the code as `registration.html`.
2. Open the file in a web browser.
3. Fill in the registration form.

## Example

The form includes:

```text
Full Name
Email
Password
Phone Number
Date of Birth
Gender
Course
Skills
Address
Register
Reset
```
